# RepRecorder 部署到别人的电脑（给使用者看的说明）

> 这份说明回答两件事：① 我在你的整合包里改过哪些东西；② 怎么把这套软件交给别人、让他们**开箱能用**。

## 一、我在你的整合包里改过哪些文件（清单 + 证据）

用"文件夹里最近被改过的时间" + 上一条会话记录交叉比对，结果如下：

| 文件 | 改了什么 | 会不会影响别人 |
| --- | --- | --- |
| `th123\modules\ReplayDnD\ReplayDnD.ini` | 只改 `MuteMusic` 一行（点界面「录BGM」→ 开=0 / 关=1） | 是**软件的正常功能**，别人电脑上也会这么改（游戏自己只读这一行） |
| `th123\modules\ReplayDnD-old\ReplayDnD.ini` | 同上 | 同上 |
| `th123\ModLoaderSettings.json` | **一次性**把被崩溃自动禁用的 `DSoundFix.dll` 改回 `enabled=true`（09-28 20:46） | 是**修复**；而且软件**从此不再读写这个文件**（见 README 第十六节），别人不受影响 |
| `th123\modules\ScoreTracker\ScoreTracker.ini` | **我没碰过** —— 上一条会话记录里一次都没出现过这个路径；那个时间是 **ScoreTracker 自己在游戏退出时保存**的 | 不影响 |
| `th123\config123.dat`、`score123.dat`、`SWRSToys.ini`、`tsk\*`、`modules\SokuLobbiesMod\*`、`modules\giuroll\giuroll.ini`、`modules\WindowResizer\WindowResizer.ini`、`replay\**\*.rep`、`replay\**\*.mp4` | **都不是我改的**（是游戏自己玩/看 rep 时写的，mp4 是录制成品） | — |

软件**只在自己的文件夹里**写这三个东西：`RepRecorder.exe` 旁边的 `RepRecorder.settings.json`（设置）、`RepRecorder.log`（日志）、`RepRecorder.已静音待恢复`（异常退出时的声音恢复标记）。
除上面 `ReplayDnD.ini` 那一行以外，软件**不写整合包里的任何配置**。

### ⚠ 新用户最容易踩的两个坑（这一版已自动处理）

1. **OBS 画布尺寸**：OBS 默认画布是 1920×1080（16:9），而游戏是 4:3 —— 不设的话录出来左右会有黑边。
   现在默认就是「自动设置画布」= 开（1440×1080，正好 4:3），新用户不会再遇到这个。
   （老设置文件里如果你手动关过它，程序仍然尊重你的选择。）
2. **`ReplayDnD` mod 没启用**：游戏就不能"带 rep 参数直接播放"，点开始录制后只会停在标题画面。
   现在点「检查环境」会明确写出 `ReplayDnD mod：已启用 ✓ / 没有启用 ⚠`。
   程序**只读不改** `ModLoaderSettings.json`（写它会和 mod loader 抢文件、导致崩溃 —— 见 README 第十六节）。

「检查环境」现在会把这五项都打出来，一眼就能看出缺什么：

```
游戏目录：…\th123
OBS     ：…\obs64.exe
WebSocket：127.0.0.1:4455（密码已获取）
ffmpeg  ：…\RepRecorder\ffmpeg.exe        ← 找不到会提示把它放到程序旁边
ReplayDnD mod（游戏能不能「带 rep 直接播放」靠它）：已启用 ✓
```

## 二、别人电脑上需要有什么（软件的依赖）

| 依赖 | 必须吗 | 软件怎么搞定 |
| --- | --- | --- |
| Windows 10/11 + .NET Framework 4.x | 必须 | Windows 自带 |
| 【完整包】非想天则整合包 | 必须 | **路径随意**。自动找：程序自己的文件夹、它上一级文件夹、上一级文件夹的各个子文件夹里的 `th123\th123.exe` |
| 整合包里的 `ReplayDnD` mod（启用状态） | 必须 | 游戏能"带 rep 参数直接播放"就靠它；整合包默认已启用 |
| OBS Studio（28 及以上，自带 obs-websocket 5.x） | 必须 | 自动找：注册表卸载项 → Program Files 等常见目录 → 每个固定磁盘里名字带 "obs" 的文件夹 |
| OBS 的 WebSocket 服务器开着 | 自动 | 程序会在 **OBS 没运行时**自动改 `%APPDATA%\obs-studio\plugin_config\obs-websocket\config.json` 把它打开；端口和密码也自动从这个文件读 |
| `ffmpeg.exe` | **并行录制必须**；单录只影响"结尾黑屏修剪 / 转 mp4" | 按顺序找：① **`RepRecorder.exe` 同目录的 `ffmpeg.exe`** ② WinGet 装的 ③ 系统 PATH 里的 |
| 显卡 | **不必须** | 并行切分默认用 NVIDIA 的 `h264_nvenc`；**没有 N 卡会自动退到 `libx264` 软件编码**（2026-09-28 新增的兜底），AMD / 核显机器也能跑 |

## 三、怎么打包给别人（推荐做法）

1. 新建一个文件夹，例如 `RepRecorder-给别人`，里面**只放**：
   - `RepRecorder.exe` ✅（就这一个文件）
   - `ffmpeg.exe`（可选但强烈建议：从 `C:\Users\江博文\AppData\Local\Microsoft\WinGet\Packages\Gyan.FFmpeg_…\ffmpeg-9.0.2-full_build\bin\ffmpeg.exe` 复制过来，约 217 MB；不复制也行，那就让用户自己装 ffmpeg，或者只做单录）
   - ❌ **不要**放 `RepRecorder.settings.json` —— 那里面有你这台机器的路径（游戏目录、OBS 路径、上次保存文件夹、WebSocket 密码），放进去别人就会继承你的路径而找不到东西。程序第一次运行会自己生成一份干净的。
   - ❌ **不要**把 `RepRecorder` 文件夹整个打包 —— 里面还有我的验证脚本、`样本-*.mp4`（约 155 MB）、`_看片` 截图等测试产物。
2. 让使用者这样做：
   - 把 `RepRecorder-给别人` 文件夹**放进整合包的上一级目录**（和你现在一样：`…\整合包2026-06-15\RepRecorder\`），这样游戏目录自动识别；
   - 或者放任意位置，第一次打开点「设置…」把「游戏目录」指过去（OBS 路径一般能自动找到）。
3. 使用者的操作顺序：
   1. **先启动一次 OBS**（不用配置什么，让它生出配置文件就行），然后关掉；
   2. 双击 `RepRecorder.exe` → 点「检查环境」，确认「游戏目录 / OBS / WebSocket」三项都正常；
   3. 把 `.rep` 拖进窗口 → 点「开始录制」。

## 四、还需要的"清理"（可选）

- 给别人的包里**不要**带 `RepRecorder.settings.json`、`RepRecorder.log`、`RepRecorder.已静音待恢复` —— 这三个都是本机状态，删掉最干净。
- 你自己这台机器上的 `ModLoaderSettings.json` 里 `DSoundFix` 的那次改动是**修复**（它本来被崩溃自动禁用了），留着就好。

---

## 五、一句话总结

**只把 `RepRecorder.exe`（可选再加一个 `ffmpeg.exe`）交出去，放在对方整合包上一级目录，先开一次 OBS，再打开软件点「检查环境」—— 就能直接用。**
