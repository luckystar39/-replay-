# RepRecorder 源码说明

> **本文件夹是"主"**：源码和 exe 都以这里为准，别的文件夹里的是副本。
> 改完代码后依次双击：`编译.bat` → `同步到所有文件夹.bat`，所有文件夹（`RepRecorder\`、`RepRecorder-给别人\`）和两个 zip 就都统一成这一份了。

## 文件
- `RepRecorder.cs` —— **全部源码就这一个文件**（约 5300 行 / 300 KB，C# 5 语法，单文件 WinForms 程序）
- `RepRecorder.exe` —— 本文件夹编译出来的程序（**这份是主，其它文件夹从它同步**）
- `编译.bat` —— 双击即可编译成 `RepRecorder.exe`（用 Windows 自带的 .NET Framework 编译器，不需要装 Visual Studio）
- `同步到所有文件夹.bat` —— 双击把本文件夹的 `RepRecorder.exe` / `RepRecorder.cs` 复制到 `RepRecorder\` 和 `RepRecorder-给别人\`，并重打两个 zip

## 怎么改、怎么编译
1. 用**记事本 / VS Code / Notepad++** 打开 `RepRecorder.cs`（**保存时选 UTF-8**，否则中文会乱码）；
2. 在**本文件夹里**改，**先关掉正在运行的 RepRecorder.exe**，双击 `编译.bat`；
3. 编译成功后双击 `同步到所有文件夹.bat` —— 完事（不用再手动往各处拷贝）。

手动编译的命令（`编译.bat` 里就是这一条）：

```
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe /nologo /target:winexe /codepage:65001 ^
  /out:RepRecorder.exe ^
  /r:System.Windows.Forms.dll /r:System.Drawing.dll /r:System.Web.Extensions.dll /r:System.Core.dll ^
  RepRecorder.cs
```

> 注意：**必须带 `/codepage:65001`**，否则源码里的中文（界面文字、日志）会编译成乱码。

## 关键设计（改代码前值得先看）
- **并行录制不是"录 N 个文件"**，而是让 OBS 录**一张网格 + N 条音轨**，录完再用 ffmpeg 按格裁（`SplitOne`，并发 `SplitParallel` 路），每格配自己那条音轨；
- 切分时会**按格分析**开头黑屏出现画面的时刻（`AnalyzeCellHead`）与结尾（`cellLastSeen`），再 `-ss/-t` 精确裁剪；
- 画面放大用 `flags=lanczos`、并往里裁 `ParallelEdgeInset` 像素（去掉格边那条亮线）；
- 「轮录」= 从队列第一个 rep 开始、按「同时录制数量」分批一路录完，**忽略选中/绿色标记**；
- 录制前会验证 OBS **真的在录**（`GetRecordStatus.outputActive`），没在录就重试一次、再不行自动重启 OBS 重跑这批，绝不白等。
