# WPF 版脱胎与优化 — 实现计划

> **给执行者：** 用 `superpowers:executing-plans`（本会话内自己实现）逐任务执行。
> 步骤用 `- [ ]` 勾选跟踪。

**Goal:** 让 RepRecorder WPF 版在编译期与运行期都不再依赖 `System.Windows.Forms`，
并实施 2026-10-12 代码审查出的全部修复项。

**Architecture:** 分三批。批 A 是结构性剥离（先抽出颜色常量让 WPF 侧脱钩，再整块删除旧界面，
最后清构建链），每步都保持可编译；批 B 是 23 项独立修复，按风险从低到高；
批 C 是代码之外的三件（发版脚本、ffmpeg 体积、产物清理）。批与批之间、批 A 的每一步之间
都跑验证脚本，保证任何一步出错都能定位到那一步。

**Tech Stack:** C# / .NET Framework 4.7.2 / WPF，用系统自带 `csc.exe` 编译（`工具\编译.bat`），
无 NuGet。测试 = `测试\验证WPF-*.ps1`（PowerShell + UIA/调试接口），无单元测试框架。

**Spec:** `RepRecorder-WPF\文档\_脱胎与优化-设计.md`

## Global Constraints

这些是每个任务都隐含遵守的：

- **不碰 git。** 用户自己管版本。任何一步都**不要** `git add/commit/checkout`，也不要提议提交。
- **`RepRecorder-旧版WinForms\` 一个字节不动**（含 `源码\`、`备份\`、`_恢复\`、`_重复副本\`、exe）。
- **不改用户可见的功能、外观、默认设置。** 唯一允许的可见变化是 §A5 的文件夹选择对话框（变现代）。
- **不碰更新通道**：`Update.cs`、`发版-生成.ps1` 的传包逻辑、`version.json`（C1 除外）。
- **源文件编码**：`src\*.cs` 是 UTF-8 无 BOM + LF；编译带 `/codepage:65001`。
  `工具\发版.bat` 是 GBK，**不要**给它加 `chcp 65001`。
- **验证脚本的使用方式**：一律 `> 文件 2>&1` 重定向 + `timeout`，**不要**用管道接
  （GUI 子进程继承管道 stdout，看着像卡死 —— R16）；启动新 exe 前要轮询调试端口，
  不要用固定 sleep（R20）；刚编译出来的 exe 立刻启动会被 Defender 卡住，脚本里已有
  `Start-Sleep 3`，别删。
- **编译前必须没有 RepRecorderWPF.exe 在跑**，`编译.bat` 会拒绝。
- **删除类改动不用切片**：按锚点行内容定位，先断言锚点唯一 + 区间字节数在预期量级，
  改完立刻编译，编译不过就从仓库外临时副本还原（R21 的教训）。
- **每个任务结束时**：跑该任务的验证 + 往 `文档\_脱胎与优化-台账.md` 追加一行
  （任务号 / 改了什么 / 命令 / 实际输出）。
- **版本号不要动。** 这一轮不升版本。

## Review Focus

这几类是设计文档隐含、但没有哪个脚本能覆盖到、且最可能咬到真实使用者的地方：

1. **选文件夹对话框**（A5）：用户点「浏览…」选背景图目录/OBS 目录时，弹不出来、或选了不生效、
   或初始目录不落在上次的位置 —— 期望是"和以前一样能选，只是长得更现代"。
2. **录制中拖入/点击的并发操作**（B11/B14/B15/B16）：录制进行时点「准备 OBS」、点「停止」、
   关窗口、拖新 rep 进队列 —— 期望是不假死、不白录、不写坏设置文件、不留下跑飞的 ffmpeg。
3. **队列很长时的界面流畅度**（B12/B13/B17）：几百个 rep 的队列在录制中滚动/框选/删行，
   以及终端攒了几千行后拖窗口 —— 期望是不闪、不卡。
4. **并行 6 格时的音源与切分**（B2/B18/C2）：同时录 6 个时切「录打击音效」、以及用
   essentials 版 ffmpeg 切分 —— 期望是 6 格都跟随、切出来的视频都有声音。
5. **旧 exe/旧快捷方式残留**（A2/A8）：用户桌面上那个 `Rep录制器.lnk`、或者谁手里还留着
   `启动旧界面-退路.bat` —— 期望是不出错、不把 `--old` 当成一个要录的文件。

- [ ] **Step 1: 建 `src\FolderPicker.cs`**

```csharp
// 选文件夹对话框（2026-10-12）。
//
// 为什么自己写：脱胎那一轮把 System.Windows.Forms 整个断掉了，而 .NET Framework 的
// WPF 里【没有】文件夹选择器（.NET Core 的 OpenFolderDialog 是后来才有的）。
// 以前用的是 WinForms 的 FolderBrowserDialog —— 它本身就是 Win32 的 SHBrowseForFolder
// 的皮，长得还是 Windows XP 那套树。这里直接调 Vista 起的 IFileOpenDialog +
// FOS_PICKFOLDERS，长得跟"另存为"是一套，跟系统里别的选择器一致。
//
// 出错就返回 null（= 用户取消）：调用方本来就只判 null，不让互操作的问题变成一个
// 用户看不懂的异常弹窗。
using System;
using System.Runtime.InteropServices;

namespace RepRecorder
{
    internal static class FolderPicker
    {
        // ---- COM 接口（vtable 顺序必须与 shobjidl.h 一致，别随手加方法）----
        [ComImport, Guid("42f85136-db7e-439c-85f1-e4075d135fc8"),
         InterfaceType(ComInterfaceType.InterfaceIsIUnknown)]
        interface IFileDialog
        {
            [PreserveSig] int Show(IntPtr parent);
            void SetFileTypes(uint cFileTypes, IntPtr rgFilterSpec);
            void SetFileTypeIndex(uint iFileType);
            void GetFileTypeIndex(out uint piFileType);
            void Advise(IntPtr pfde, out uint pdwCookie);
            void Unadvise(uint dwCookie);
            void SetOptions(uint fos);
            void GetOptions(out uint pfos);
            void SetDefaultFolder(IShellItem psi);
            void SetFolder(IShellItem psi);
            void GetFolder(out IShellItem ppsi);
            void GetCurrentSelection(out IShellItem ppsi);
            void SetFileName([MarshalAs(UnmanagedType.LPWStr)] string pszName);
            void GetFileName([MarshalAs(UnmanagedType.LPWStr)] out string pszName);
            void SetTitle([MarshalAs(UnmanagedType.LPWStr)] string pszTitle);
            void SetOkButtonLabel([MarshalAs(UnmanagedType.LPWStr)] string pszText);
            void SetFileNameLabel([MarshalAs(UnmanagedType.LPWStr)] string pszLabel);
            void GetResult(out IShellItem ppsi);
            void AddPlace(IShellItem psi, int fdap);
            void SetDefaultExtension([MarshalAs(UnmanagedType.LPWStr)] string pszDefaultExtension);
            void Close(int hr);
            void SetClientGuid(ref Guid guid);
            void ClearClientData();
            void SetFilter(IntPtr pFilter);
            void GetResults(out IntPtr ppenum);
            void GetSelectedItems(out IntPtr ppsai);
        }

        [ComImport, Guid("43826d1e-e718-42ee-bc55-a1e261c37bfe"),
         InterfaceType(ComInterfaceType.InterfaceIsIUnknown)]
        interface IShellItem
        {
            void BindToHandler(IntPtr pbc, ref Guid bhid, ref Guid riid, out IntPtr ppv);
            void GetParent(out IShellItem ppsi);
            void GetDisplayName(uint sigdnName, [MarshalAs(UnmanagedType.LPWStr)] out string ppszName);
            void GetAttributes(uint sfgaoMask, out uint psfgaoAttribs);
            void Compare(IShellItem psi, uint hint, out int piOrder);
        }

        const uint FOS_PICKFOLDERS    = 0x00000020;
        const uint FOS_FORCEFILESYSTEM= 0x00000040;
        const uint FOS_PATHMUSTEXIST  = 0x00000800;

        const int  HRESULT_CANCELLED  = unchecked((int)0x800704C7);

        [DllImport("ole32.dll")]
        static extern int CoCreateInstance(ref Guid rclsid, IntPtr pUnkOuter, uint dwClsContext,
                                           ref Guid riid, [MarshalAs(UnmanagedType.Interface)] out object ppv);

        [DllImport("shell32.dll", CharSet = CharSet.Unicode)]
        static extern int SHCreateItemFromParsingName(
            [MarshalAs(UnmanagedType.LPWStr)] string pszPath, IntPtr pbc,
            [MarshalAs(UnmanagedType.LPStruct)] Guid riid,
            [MarshalAs(UnmanagedType.Interface)] out IShellItem ppv);

        static readonly Guid CLSID_FileOpenDialog =
            new Guid("DC1C5A9C-E88A-4dde-A5A1-60F82A20AEF7");
        static readonly Guid IID_IFileDialog =
            new Guid("42f85136-db7e-439c-85f1-e4075d135fc8");

        internal static string Pick(string title, string initialDir)
        {
            object o = null;
            try
            {
                Guid clsid = CLSID_FileOpenDialog, iid = IID_IFileDialog;
                if (CoCreateInstance(ref clsid, IntPtr.Zero, 1 /*CLSCTX_INPROC_SERVER*/, ref iid, out o) != 0)
                    return null;
                IFileDialog d = (IFileDialog)o;

                uint opts;
                d.GetOptions(out opts);
                d.SetOptions(opts | FOS_PICKFOLDERS | FOS_FORCEFILESYSTEM | FOS_PATHMUSTEXIST | FOS_NOCHANGEDIR);

                if (!string.IsNullOrEmpty(title)) d.SetTitle(title);

                // 初始目录：设不上就算了（比如上次那个目录已经被删了），别因此弹不出来。
                if (!string.IsNullOrEmpty(initialDir) && System.IO.Directory.Exists(initialDir))
                {
                    try
                    {
                        IShellItem start;
                        Guid shellItemIid = new Guid("43826d1e-e718-42ee-bc55-a1e261c37bfe");
                        if (SHCreateItemFromParsingName(initialDir, IntPtr.Zero, shellItemIid, out start) == 0)
                            d.SetFolder(start);
                    }
                    catch { }
                }

                int hr = d.Show(IntPtr.Zero);
                if (hr == HRESULT_CANCELLED) return null;
                if (hr != 0) return null;

                IShellItem res;
                d.GetResult(out res);
                string path;
                res.GetDisplayName(SIGDN_FILESYSPATH, out path);
                return string.IsNullOrEmpty(path) ? null : path;
            }
            catch (Exception ex)
            {
                Log.Write("选文件夹对话框出错（已当作取消）：" + ex.Message);
                return null;
            }
            finally
            {
                if (o != null) try { Marshal.ReleaseComObject(o); } catch { }
            }
        }
    }
}
```

```csharp
static StreamWriter logWriter;         // 懒建

static void Write(string s)
{
    lock (gate)
    {
        try
        {
            if (logWriter == null)
            {
                Directory.CreateDirectory(Path.GetDirectoryName(LogPath));
                logWriter = new StreamWriter(new FileStream(LogPath, FileMode.Append, FileAccess.Write,
                                                            FileShare.ReadWrite),
                                             new UTF8Encoding(false));
                logWriter.AutoFlush = true;     // ⚠ 必须是 true
            }

        }
        catch { /* 日志失败不能影响主流程 */ }
    }
}
```
